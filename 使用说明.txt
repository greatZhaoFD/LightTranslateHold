轻译 · 按住版 v1.0.4（便携版）
================================

首次使用：
1. 双击 LightTranslateHold.exe（Windows 10/11 x64，需要 .NET Framework 4.8）。
   第一次启动会自动打开设置窗口，填写 API Key 后保存。
2. 以后启动：程序静默进入右下角托盘，不弹设置窗口。需要改配置时右键托盘图标（或双击图标）→ 设置…。
3. 开机自启始终静默进托盘，不弹窗。

翻译：
- 在任意支持复制的应用里选中文字，按下 Alt+1（按住或轻按都行），译文出现在选区/光标下方。
- 浮窗不会自动消失；按 Esc 或点击浮窗外部才关闭；点击浮窗内“复制”不会关闭。
- 再次按 Alt+1 会取消上一次并翻译新选区。

API：
- 设置里预设包含 DeepSeek、阿里云百炼（DashScope）、OpenAI、本地 Ollama、自定义。
- 任何 OpenAI 兼容服务都可以选“自定义”，填 Base URL、模型名、API Key。
- 百炼兼容地址：https://dashscope.aliyuncs.com/compatible-mode/v1（模型如 qwen-plus）。

本版修复：
- 首次启动自动打开设置，后续启动静默托盘。
- 按下 Alt+1 立即触发，不再等 150ms（解决时灵时不灵）。
- 取消自动消失，改为 Esc / 点击浮窗外关闭。
- 修复 Alt+1 保存/显示归一化。
- 新增鼠标钩子点击浮窗外关闭。

注意：
- 未做商业代码签名，SmartScreen 可能提示未知发布者。
- 只翻译可复制的文字，不支持图片/扫描件 OCR。
- 原文会发送到你配置的 API 服务商；程序不收集数据、不保存历史。
- Alt+1 是系统级快捷键；若某些程序弹 Alt 菜单，可在设置里换成 Ctrl+Alt+Q 或 F8。
- 详细说明见 README.md；测试记录见 docs/测试记录.md。
- 基于 MIT 开源项目 LightTranslate v1.0.0 改造。
